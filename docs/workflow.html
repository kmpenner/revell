Project workflow

The Revell Digital Corpus is produced by student research assistants, following the pipeline set out in the Fr. Ed Gatto Chair proposal (2026). This page documents it so that future students can continue and reuse the work. The scripts live in the project repository's scripts/ folder.

  1. Inventory and metadata. Each item has an ID from Revell's own bibliography (07a = articles, 07b = books, 08 = book reviews), recorded in metadata/bibliography.json. build_records.py turns it into metadata/records.json, the item-level record shown on the catalogue.
  2. Rights review. For each item, record the publisher or rights holder, its policy, and any permission request in the item's rights_* fields of records.json. Status values: pending, open, permission granted, restricted. A restricted item needs a summary. The site then shows the record and summary instead of the text, and the scans stay internal.
  3. Archival scanning. Offprints are scanned at 400 dpi into scans/, then split and cropped per article into 07a Articles/<ID> - <short title>/.
  4. OCR and correction. AI-assisted OCR produces transcription.md. The student proofreads it against the facsimile, with particular care for Hebrew vowel points and Masoretic accents.
  5. TEI encoding. md_to_tei.py wraps the corrected text in TEI P5: page breaks (<pb/>), headings, notes, italics, and Hebrew marked as <foreign xml:lang="he">. build_records.py writes the bibliographic and rights record into the teiHeader.
  6. Validation. validate_tei.py checks every file against the TEI P5 schema (tei_all.rng) and writes reports/tei_validation.md. Fix every error before publishing.
  7. Publication. Run generate_site.py, then build_records.py, then build_search.py. Commit docs/, which GitHub Pages serves.
